# Practica 3: Control de versiones con Git y GitHub

Repositorio creado para el taller de gestion de codigo y documentacion de **Ingenieria del Software** (*Universidad de Cordoba*).

___

## Objetivos trabajados
1. Fundamentos de los sistemas de control de versiones distribuidos.
2. Creacion y manejo de repositorios locales y remotos en GitHub.
3. Gestion de ramas y fusiones.
4. Documentacion basica mediante lenguaje **Markdown**.

## Flujo de trabajo aplicado
* Preparacion de archivos modificados en el *Staging Area* con git add.
* Confirmacion de cambios mediante instantaneas (*snapshots*) con git commit.
* Sincronizacion con el repositorio remoto mediante git push.

> Nota: Repositorio de seguimiento sincrono de la practica.

Mas informacion en la [documentacion oficial de Git](https://git-scm.com/doc).
